# 症例報告用匿名化ガイド

このスキルは学会発表や論文投稿用の症例報告に特化しています。

## 識別子の取り扱い（厳格モード）

| カテゴリ | 処理方法 | 例 |
|---------|----------|-----|
| 氏名 | 完全削除 | 山田太郎 → **** |
| 年齢 | 10歳刻み | 47歳 → 40代 |
| 生年月日 | 削除 | **** |
| 住所 | 地方のみ | 東京都 → 関東地方在住 |
| 日付 | X年Y月形式 | 2024/03/15 → X年3月 |
| 病院名 | 匿名化 | ○○病院 → A病院 |

## 学術的価値の維持

- 臨床経過の時系列は相対日数で保持
- 検査結果・画像所見の詳細は保持
- 診断・治療のロジックは保持

## 特記事項

- 5人未満の希少症例は特に注意
- 写真・画像がある場合は顔の匿名化を推奨
- 遺伝情報は原則削除
- 同意取得の有無を確認するよう促す
